1. Visão Geral do Projeto

Descrição:

O projeto consiste no desenvolvimento de uma aplicação web interativa que permite aos utilizadores responder a um questionário sobre conteúdos relacionados com a disciplina de Multimédia. A aplicação apresenta um conjunto de 12 perguntas de escolha múltipla, permitindo testar conhecimentos sobre diferentes áreas, como imagem digital, áudio, vídeo, animação, formatos de ficheiros e desenvolvimento web.

O principal objetivo é proporcionar uma forma dinâmica e interativa de estudar e consolidar conhecimentos sobre Multimédia, permitindo ao utilizador verificar as suas respostas, consultar explicações e avaliar o seu desempenho através de uma classificação final.

A aplicação foi desenvolvida para funcionar diretamente num navegador, sem necessidade de instalar programas adicionais ou utilizar um servidor externo. Também foi preparada para ser publicada através do GitHub Pages.

2. Estrutura do Código e Funcionalidades Integradas

Para o desenvolvimento deste projeto foram utilizados conhecimentos adquiridos nas fichas práticas da disciplina, complementados com algumas funcionalidades desenvolvidas com o auxílio de Inteligência Artificial.

A aplicação utiliza HTML para construir a estrutura da página, CSS para definir a apresentação visual e JavaScript para controlar o funcionamento do questionário, verificar as respostas e calcular os resultados.

Entre as principais funcionalidades implementadas encontram-se:

Apresentação de 12 perguntas relacionadas com a disciplina de Multimédia.
Disponibilização de quatro opções de resposta para cada pergunta.
Seleção interativa das respostas pelo utilizador.
Verificação automática das respostas selecionadas.
Identificação visual das respostas corretas e incorretas.
Apresentação de explicações após cada resposta.
Barra de progresso que acompanha o desenvolvimento do questionário.
Contabilização automática da pontuação final.
Apresentação do número de respostas corretas e incorretas.
Cálculo da percentagem de aproveitamento.
Mensagens personalizadas de acordo com a classificação obtida.
Possibilidade de repetir o questionário.

Foi também utilizada a tecnologia JavaScript para garantir a interação entre os diferentes elementos da página, permitindo que todo o questionário funcione diretamente no navegador.

3. Registo de Utilização da IA

Durante o desenvolvimento foi utilizada Inteligência Artificial como ferramenta de apoio à programação, permitindo esclarecer dúvidas, corrigir erros, melhorar a organização do código e desenvolver novas funcionalidades.

1. Prompt para construção da interface Web

"Cria uma aplicação web utilizando HTML, CSS e JavaScript para um questionário sobre Multimédia. Pretendo uma interface moderna, simples e organizada, inspirada no design visual do GitHub, com um tema escuro, elementos azuis, cartões com contornos discretos e uma apresentação adaptável a diferentes tamanhos de ecrã."

2. Prompt para construção do questionário

"Desenvolve um questionário interativo sobre a disciplina de Multimédia com aproximadamente 12 perguntas de escolha múltipla. Cada pergunta deve apresentar quatro opções de resposta, permitir selecionar apenas uma opção e verificar automaticamente se a resposta está correta. Inclui explicações para as respostas, uma barra de progresso e uma classificação final com o número de respostas corretas e incorretas."

3. Prompt para compatibilidade com GitHub Pages

"Adapta a aplicação para funcionar através do GitHub Pages. Remove a dependência de Python, Flask e Jinja2, utilizando apenas HTML, CSS e JavaScript. Organiza os ficheiros de forma simples, garantindo que a aplicação funciona diretamente no navegador sem necessitar de um servidor backend."

4. Dificuldades e erros corrigidos com a IA

Durante a construção da aplicação surgiram algumas dificuldades relacionadas com a organização dos ficheiros e a comunicação entre HTML, CSS e JavaScript.

Uma das principais alterações foi a substituição da estrutura inicialmente pensada com Python e Flask por uma solução totalmente baseada em tecnologias frontend. Esta alteração foi necessária porque o GitHub Pages permite alojar páginas estáticas, não executando diretamente aplicações Python ou servidores Flask.

Outra dificuldade foi implementar corretamente a lógica do questionário, nomeadamente a seleção das respostas, a verificação automática, a atualização da pontuação e a apresentação dos resultados.

Com o auxílio da IA foi possível organizar melhor o código, identificar possíveis erros e implementar funcionalidades de interação e apresentação visual.

4. Otimização de Layout

Foi pedido à Inteligência Artificial que ajudasse a desenvolver uma interface inspirada no design do GitHub, procurando obter uma apresentação moderna, organizada e intuitiva.

Foram consideradas alterações como:

Utilização de um tema escuro inspirado no GitHub Dark Mode.
Aplicação de tons de cinzento e azul na interface.
Utilização de fontes sem serifa para melhorar a legibilidade.
Criação de cartões com contornos discretos para organizar o conteúdo.
Utilização de botões interativos com efeitos visuais.
Destaque das respostas corretas através da cor verde.
Destaque das respostas incorretas através da cor vermelha.
Implementação de uma barra de progresso dinâmica.
Organização dos elementos através de margens e espaçamentos.
Adaptação da interface a computadores, tablets e telemóveis.

O objetivo foi criar uma experiência de utilização agradável, mantendo uma identidade visual semelhante à plataforma GitHub e facilitando a utilização do questionário.

5. Estrutura de Ficheiros do Repositório

A organização do projeto foi realizada de forma a separar a estrutura da página, a apresentação visual e a lógica de funcionamento da aplicação.

index.html – Ficheiro principal responsável pela estrutura da página, apresentação do questionário e organização dos diferentes elementos da interface.
style.css – Folha de estilos responsável pela formatação visual, cores, tipografia, organização dos elementos e adaptação a diferentes ecrãs.
script.js – Ficheiro responsável pelo funcionamento do questionário, gestão das perguntas, seleção e correção das respostas, cálculo da pontuação e apresentação dos resultados.
README.md – Documento com a descrição do projeto, funcionalidades, tecnologias utilizadas e registo do desenvolvimento.

A aplicação foi organizada para funcionar diretamente no navegador, sem necessidade de backend ou instalação de dependências adicionais.
